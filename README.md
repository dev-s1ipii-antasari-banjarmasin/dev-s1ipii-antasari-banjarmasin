## 📖 Tentang Kami

<img align="right" src="Logo IPII November-16.jpg" alt="Logo Emblem IPII" width="200">

**Program Studi Ilmu Perpustakaan dan Informasi Islam (IPII)** di Universitas Islam Negeri (UIN) Antasari Banjarmasin berdedikasi untuk mencetak pustakawan, pengelola informasi, dan arsiparis yang tidak hanya unggul dalam manajemen perpustakaan tradisional, tetapi juga adaptif terhadap perkembangan teknologi informasi digital.

Melalui akun GitHub ini, kami berbagi proyek-proyek inovatif, modul pembelajaran, kode sumber terbuka (open-source), dan kolaborasi riset yang dikembangkan oleh dosen dan mahasiswa IPII.

---

## 🎯 Fokus Pembelajaran & Pengembangan

Di repositori ini, Anda akan menemukan berbagai proyek yang berkaitan dengan:
- 🏛️ **Sistem Otomasi Perpustakaan**: Kustomisasi dan pengembangan sistem seperti SLiMS (Senayan Library Management System) dan INLISLite.
- 💾 **Repositori Institusi & Arsip Digital**: Pengelolaan data menggunakan DSpace, EPrints, dan Omeka.
- 📊 **Ilmu Informasi & Analisis Data**: Proyek *data mining*, bibliometrik, dan visualisasi data perpustakaan.
- 🌐 **Pengembangan Web & Aplikasi**: Sistem informasi akademik, web perpustakaan desa, dan aplikasi literasi digital.
